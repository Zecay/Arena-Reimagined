Themes

Applied instantly on every arena.ai page. Switch themes from the gear button in the composer toolbar, or from the popup / this page. Import a theme.json from anywhere — or ask your favourite AI to write one.

Features

Every feature runs in isolation. If one crashes, it disables itself and reports here — the rest keep working, and the page is never affected.

Health & Diagnostics

Run the offline WCAG scan on this page against any of the bundled fixture themes to reproduce the contrast report (see tools/contrast-scan.js).

Danger zone

Reset all Arena Reimagined settings back to defaults (theme, toggles, everything).

Want a feature that isn't here? Contact zecayy on Discord.

Arena Reimagined is open source on GitHub — not on the Chrome Web Store. Independent community project, not affiliated with Arena AI. Host-upload is the only thing that leaves your machine (after you accept).
